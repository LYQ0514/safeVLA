# VLPSA 复现与三方对比报告

- **日期**：2026-10-30
- **上游**：VLPSA (arXiv 2609.22462)，Caltech Ames 组，无代码
- **复现方式**：方案 B（核心思想复现：PSF + 全身采样），协议对齐本项目
- **规模**：1600 条 episode（32 场景 × 50）

---

## 一、总体结论

| 方法 | TSR | CAR | CAR>5mm | SSR | ETS |
|---|---|---|---|---|---|
| π0.5 基线 | **59.8%** | 13.8% | 87.7% | 12.4% | 259.7 |
| AEGIS | 44.9% | **60.4%** | 96.6% | **32.2%** | 302.1 |
| **VLPSA（我们复现）** | 41.7% | 19.8% | 91.2% | 10.4% | 293.0 |

**核心结论：VLPSA 全身 CBF 在本项目协议下全面落后 AEGIS。**

- CAR 只到 19.8%（AEGIS 60.4%），避障能力远弱
- TSR 41.7% 甚至低于裸基线 59.8%，安全层严重损害任务
- **SSR 10.4%，三方最差**（基线 12.4%、AEGIS 32.2%）

唯一亮点是 `CAR>5mm=91.2%`（无严重碰撞），略高于基线 87.7%，
说明它在"避免撞飞障碍物"上有一点作用，但远不如 AEGIS 的 96.6%。

## 三、为什么 VLPSA 复现效果差（根因分析）

### 3.1 干预率与成功率负相关（实测证据）

把 1600 条 episode 按干预率分桶：

| 干预率区间 | episode 数 | TSR |
|---|---|---|
| [0, 0.2) | 180 | 33% |
| [0.2, 0.4) | 134 | 37% |
| [0.4, 0.6) | 289 | 28% |
| [0.6, 0.8) | 172 | 26% |
| [0.8, 1.0) | 185 | **14%** |

相关系数 −0.15，**干预越多，成功越少**。这是"过度约束"的直接证据。

### 3.2 全身采样 vs 末端椭球：保守性的本质差异

- AEGIS：单末端椭球，只在末端靠近障碍时约束 → 约束精准、代价小
- VLPSA：815 个采样点覆盖整条机械臂 → 任何 link 靠近障碍都触发约束

在 SafeLIBERO 这种桌面操作场景，**障碍物都在桌面高度，只有末端会接近它们**。
全身约束保护了那些根本不会碰到障碍的 link，白白限制了运动。

**关键反讽**：论文声称全身安全是优势（保护 Level II 的持物运输），
但我们的协议下，这个优势没体现，代价却放大了。

### 3.3 与论文的差距（诚实归因）

论文 VLPSA：CAR 91.2% / SR 55.5%。我们：CAR 19.8% / TSR 41.7%。

差距可能来自：
1. **协议不同**：论文 100Hz joint-velocity + 深度传感器 + 持物保护，我们 20Hz OSC + oracle + 无持物保护
2. **我们未实现持物保护**（论文的 Level II 优势正来自它）
3. **occupancy 分辨率**：我们 0.03m，论文多分辨率（3cm 粗 + 1cm 细）
4. **采样点几何**：我们用 mesh AABB 近似，论文可能更精确

但注意：论文自己也承认 VLPSA 的 SR（55.5%）**低于** VLSA*/AEGIS（68.1%），
SSR（52.1%）也略低（54.4%）。所以"VLPSA 牺牲任务换安全"是方法本身的特性，
我们的复现只是把这个 trade-off 放大了。

## 四、这个结果的价值（不是失败）

1. **诚实记录**：VLPSA 在统一协议下不如 AEGIS，这是有价值的负结果。
   说明"全身安全"在当前 SafeLIBERO 场景和 20Hz 协议下并不划算。

2. **印证论文自己的局限**：论文的 SSR 也没赢 AEGIS，我们的复现与之一致。

3. **long 套件的亮点**：VLPSA 在长程任务上 TSR 不崩（62%/51% vs 基线 62%/55%），
   这是 AEGIS 做不到的。说明全身 CBF 的"温和约束"在特定场景有价值。

4. **方法学贡献**：我们建立了一个可扩展的 PSF + 全身采样框架，
   后续可以调 occupancy 分辨率、采样密度、加持物保护来逼近论文。

## 五、复现命令

```bash
cd /data/safeVLA && source tools/activate_env.sh
setsid nohup python tools/run_eval_vlpsa.py --all --no-video \
    --resolution 1024 --replan-steps 5 --cbf-gain 1 \
    --out data/eval/vlpsa_1024 --resume \
    > .cache-local/eval_vlpsa.log 2>&1 < /dev/null &
```

耗时约 5 小时（1024 分辨率，filter 12.5ms/次）。

## 六、后续可改进方向（若要逼近论文）

1. **持物保护**（论文 Level II 的核心优势，我们未实现）
2. **occupancy 多分辨率**（论文 3cm 粗 + 1cm 细，我们单 3cm）
3. **采样点几何精确化**（mesh 顶点而非 AABB 角点）
4. **调 cbf_gain 与采样密度**（当前 γ=1，815 点；可扫描）

但**优先级待定**：当前结果是"全身 CBF 不如末端 CBF"的清晰结论，
是否值得投入逼近论文，取决于主方法的需求。
