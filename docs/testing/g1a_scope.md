## 0. 命名与定位

本实验正式命名为 **G1a：Long-I / task0 CRN Pilot**。

它是有效的**局部先导实验**，但**不符合最初预注册的分层设计**（原计划 Long-I + Long-II）。

## 1. 原计划 vs 实际执行（公开记录偏差）

| 维度 | 原计划 | 实际执行 |
|---|---|---|
| SafeLIBERO Level | Long-I + Long-II | **仅 Long-I** |
| Task | 跨两 Level 分层 | **仅 task0** |
| 初始状态 | 两 Level 各 8 | task0 的 episode 0–15 |
| 随机流 | 每状态 3 | 每状态 3 |
| CRN 配对 | 48 | 48 |
| Rollout | 96 | 96 |

> 此偏差如实记录，不事后包装成「原本就计划如此」。

## 2. 估计对象（严格限定）

$$\Delta_{\mathrm{TSR}}^{I,0} = \mathbb E_{s,\omega}\left[ Y_{\mathrm{AEGIS}}(s,\omega) - Y_{\pi_{0.5}}(s,\omega) \mid \mathrm{Long\!-\!I,\ task0} \right]$$

- 16 个固定初始状态**不是从任务分布随机抽取**，最直接的估计对象是
  「这 16 个状态上、对指定随机流分布取平均的处理效应」。
- **不能**推广到所有 Long-I 任务，**更不能**推广到 Long-II 或完整 SafeLIBERO。

## 3. 三层分析能力

| 层 | 内容 | 状态 |
|---|---|---|
| 1 | 任务成功配对效应（n11/n10/n01/n00 + Δ_TSR）| 可估计 |
| 2 | 联合安全任务（TSR/CAR/SSR 配对）| 可估计 |
| 3 | 跨 Level / 跨任务泛化 | **Not Evaluated** |

> 不以 task0 结果推断 Long-I/II 差异。

## 4. 不确定性

- 用初始状态作聚类单位做配对 Bootstrap；
- 同时报告原始翻转数量 n10/n01；
- 16 状态 × 3 流 = 48 对，置信区间可能很宽，保留不确定性。

## 5. 后续 G1b（暂不启动）

若要补全跨 Level 研究目标，须**重新制定前瞻性协议**，提前固定 Level/Task/Init State/种子。

且不能简单「对称加 16 个 Long-II 状态」：必须核实 Long-I/task0 与 Long-II/task0 的
任务语义与场景配置是否可比（否则差异混合了 Level 与具体任务的影响）。

## 6. 科研原则（冻结）

- 实验设计偏差**公开记录**；
- 不因偏差**否定所有有效数据**；
- 不通过**事后修改研究问题**把局部结果包装成完整验证。
