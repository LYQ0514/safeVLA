## 0. 复核原则

Contact-free 与 CAR 是两个独立证据来源：
- **CAR** = mug 历史位移（`sim.data.xpos` 真值），不依赖接触清单；
- **Contact-free** = robot↔受保护物体无接触，依赖障碍物清单的完整性。

接触清单遗漏不推翻 CAR 数值，但**撤回**未被完整清单支持的「零禁止接触」结论。

## 2. P4-P0「几何路径无碰撞」撤回

对 S01/S04/S09，新旧契约下多起点 IK 无碰撞解数对比：

| 预抓取位姿 | S01 旧/新 | S09 旧/新 |
|---|---|---|
| 正上方 z+0.14 | 0 / 0 | 0 / 0 |
| +y 侧向 0.10/0.14 | **7 / 0** | **8 / 0** |
| +y 侧向 0.06/0.12 | 3 / 0 | 5 / 0 |

精确归因（只加底座 geom，不加摆设）：侧向 IK 解从 7 个归零。底座 box 在 y 方向
延伸覆盖 soup 抓取区域，真实阻挡侧向接近。

**结论**：P4-P0 的「安全抓取路径存在」建立在漏检底座几何上，**撤回**。但这不证明
「完全不存在安全路径」——只测了 6 个预定义位姿 + 固定朝下方向，可能存在其他
方向/位姿的无碰撞解。

「几何可行、动力学不可行」的叙事修正为：「在完整几何契约下，当前预定义候选集的
几何路径本身就不无碰撞」。

## 5. E1 的 CRN 缺陷（独立记录，非本次引入）

`generate_block` 硬编码 state2/stream0，导致 E1 的「12 组」实际只有 4 个独立状态
（每个状态 3 个 stream 复用相同噪声）。E1 不能作为 12 条独立随机流的统计样本，
只能作为「4 个状态的跨状态结论」。这与本次接触清单 bug 独立，但需一并记录。
