# D1+D2 接近可行性审计

> 日期：2026-11-01
> 状态：机制判决。主线「Safety without Task Degradation」的核心诊断。
> 前置：`g1a_soup_subgoal_failure_audit.md`、`g1a_w2_cross_worker.md`。

---

## 0. 结论（精准表述）

> AEGIS 在 soup 接近阶段的部分关键时刻，把正向接近名义动作修正为负向；
> 但 step15/20 的代理 QP 约束**并未禁止正向接近**（γ_max≈81mm），
> 且「避免反向动作」的额外 QP 代价极小（ΔJ(γ≥0)≈0.02）。
> 因此问题**不是安全约束过严，也不是简单「优化目标错了」**，而是
> 「最小偏离名义」目标在椭球 CBF 约束几何下，其**全局最优解**不满足任务接近方向。

> **数学勘误（2026-11-01）**：AEGIS 的 QP 是正定二次目标 + 线性约束的**凸 QP**，
> 解是**全局最优解**，不是「局部最优解」。正确表述：$u^*=\arg\min_{u\in\mathcal F} J_{AEGIS}(u)$
> 满足 $\gamma(u^*)<0$，但 $\exists \tilde u\in\mathcal F: \gamma(\tilde u)>0$。
> 这揭示的是「优化目标与任务进度目标不一致」，不是「优化器陷入局部极小值」。

## 1. 已证实的事实

| 指标 | step15 | step20 |
|---|---|---|
| γ_nom（名义接近分量）| +14.5mm | +13.8mm |
| γ_AEGIS（实际过滤）| −4.7mm | −4.9mm |
| γ_max（可行域最大接近）| +81.6mm | +81.1mm |
| ΔJ(γ≥0) | 0.023 | 0.023 |
| ΔJ(γ≥γ_nom) | 0.39 | 0.33 |

$$\gamma_{\max}^{\mathcal F} > 0 \;\land\; \gamma_{\mathrm{AEGIS}} < 0$$

## 2. 量纲与约束版本（记录）

- γ 单位 = 米（动作平移分量 × 0.05m 缩放，投影到 soup 方向）；
- 硬约束 QP（无松弛变量，已核实 `filter` 代码）；
- γ_max 的优化：动作空间 a ∈ [-1,1]^6 + u_z 自由，s.t. 单条 CBF 约束
  `a_u_v·u_v + a_u_omega·u_omega + a_uz·u_z + 10h ≥ 0`，u_v=5R1ᵀa_v, u_omega=5a_omega。

## 3. 关键发现：γ_max≈81mm 是「极端动作」

- γ_max=81mm 接近动作盒允许的最大位移范数（86.6mm = √3×50mm）；
- 最优接近动作 `a_max[:3]=[1,-1,-1]`（动作盒角落），与名义 `[0.35,-0.28,0.01]` 差异巨大；
- **正向接近「可行」但需要大幅偏离名义动作**——不能理解为「存在大量易实现的安全接近空间」。

## 4. 机制解释（分级）

| 层级 | 结论 | 状态 |
|---|---|---|
| 已证实 | 部分关键时刻，正向名义被修正为负向；约束未禁正向 | ✅ |
| 得到支持 | CBF 约束几何 + 最小偏离目标 → QP **全局最优解**未保留接近分量 | ✅（ΔJ 证据）|
| 待验证 | 正向候选能否真实物理安全执行、能否帮助 π0.5 恢复 soup | 待 C1 |
| 不提前宣称 | 任务损失「完全由优化目标造成」；「加方向奖励即可解决」| — |

## 5. ΔJ 的判别意义

- **ΔJ(γ≥0)=0.02**：避免反向动作几乎免费 → 轻量「任务方向保持」约束可能有效；
- **ΔJ(γ≥γ_nom)=0.39**：保留完整接近分量需较大代价，但仍可行 → 不是「γ_nom 不可行」。
- 但 γ≥0 只保证「不远离」，不保证「能抓取」；正向候选的横向位移、旋转、真实安全需进一步验证。

## 6. 尚未证明的（诚实边界）

1. 正向接近候选（a_max=[1,-1,-1]）在**真实物理执行**中是否仍安全（QP 代理可行 ≠ 物理安全）；
2. 这种「任务方向保持」能否让后续 π0.5 **恢复 soup 任务进度**（而非只是当前步不远离）；
3. 任务损失是否**完全**由 QP 目标造成（可能还有闭环状态退化等复合因素）。

## 7. 候选算法方向（待验证，非结论）

**Task-Progress-Preserving Safe Action Selection**：

不能简单写成 $\min_a \|a-a_{nom}\|^2 - \lambda \gamma(a)$（可能诱导横向运动/错误姿态/新碰撞）。

更值得探索：在满足实际安全条件的候选中，选择「保持子目标进度 + 不使后续 π0.5 陷入停滞」的动作。

两个层次：
- 局部正向进度是否可实现（D2 已答：是，代价小）；
- 该进度能否保留未来闭环任务成功（待 C1）。
