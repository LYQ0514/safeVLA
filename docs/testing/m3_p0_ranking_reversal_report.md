## 0. 结论（回答决定性问题的答案）

> **是**。在独立 2D 单积分器 + 圆形障碍 + 冻结 PD 朝目标策略的最小模型中，
> 「当前修正最小的 QP 解」系统性导致「更大的未来干预负担」。一般场景（目标随机
> 位置）下排序反转率约 **80%**，且反转场景**全部不损任务进度、未来违规 0**。

机制：QP 解「贴 CBF 边界滑行」→ 未来持续触发约束（未来 8 步平均干预 3.22 次）；
切向绕行「主动绕过」→ 一次绕开后约束减少（2.15 次），且绕行改善任务进度。

## 1. 系统与定义

- 单积分器 2D：`s=[x,y]`，`u=[vx,vy]`（速度控制），`s' = s + u·dt`；
- 圆形障碍 CBF（相对度 1）：`n^T u ≥ b`，`n=(p-c)/‖p-c‖`，`b=-α·(‖p-c‖-(r+margin))`；
- 冻结策略：`u^π = -K(p-goal)`（PD 朝目标，定期重规划）；
- QP 解：`u^QP = argmin ‖u-u^π‖² s.t. n^T u ≥ b`（当前修正最小，贴边界）；
- 切向绕行候选：`u^side = QP 投影(u^π + t·0.8‖u^π‖)`（沿切向主动绕过）；
- 未来负担：`D_H = Σ γ^{k-1} ‖u^safe_{t+k} - u^π_{t+k}‖²`，未来 u^π 来自真实重规划。

## 2. 结果

### 2.1 排序反转率

| 场景族 | 反转率 | 不损任务率 | 场景数 |
|---|---|---|---|
| 正对穿障（目标在障碍正后方）| 100% | 100% | 500 |
| **一般（目标随机位置）** | **~80%** | **100%** | ~280 |

参数稳健性：K∈{0.5,1,2}、α∈{1,2,4}、r∈{0.2,0.3,0.5}、H∈{2,4,6} 全组合下反转率
100%（正对穿障族）；一般场景 3 个 seed 反转率 0.80-0.83。

### 2.2 机制证据（未来干预次数 vs 违规）

| 候选 | 未来 8 步干预次数 | 未来 8 步违规次数 |
|---|---|---|
| QP（贴边界）| 3.22 | 0 |
| 切向绕行 | 2.15 | 0 |

切向绕行减少了未来干预次数（3.22→2.15），且**未来违规 0**（绕行不牺牲安全）。

### 2.3 任务进度

| 候选 | 任务进度（朝目标靠近）|
|---|---|
| QP（贴边界滑行）| 0.041 |
| 切向绕行 | 0.754 |

切向绕行**明显改善**任务进度（0.041→0.754），不是靠停下换安全。

## 3. 关键机制解释

QP 的「最小修正」投影把动作拉到 CBF 边界（`n^T u = b`），机器人沿障碍表面滑行，
**未来每步都触发约束**（负担大，且滑行偏离目标）。切向绕行「主动绕开」障碍，
未来约束不再持续激活（负担小，且绕过后直接朝目标）。

这正是「排序反转」的物理来源：

$$\boxed{\|u^{QP}-u^\pi\| < \|u^{side}-u^\pi\| \quad\text{但}\quad D_H(u^{QP}) > D_H(u^{side})}$$

## 4. 诚实边界

1. **最小模型**：单积分器 2D，非 SafeLIBERO/π0.5 真实闭环；
2. **100% 是退化**：正对穿障族（目标在障碍正后方）是构造的特殊子集；
   一般场景 ~80% 是更有意义的结果；
3. 切向绕行方向是**预注册规则**选取（选任务进度更好的切向），非事后挑选；
4. 尚未触及「未来负担预测器」（M3-P1 的事）。
