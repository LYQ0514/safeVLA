## 0. 结论

在 46 个「发生安全干预」的真实 QP 快照上，CCA-ASF（β_max=4）相对欧氏 AEGIS：

- **ΔD_∥ < 0（46/46）**：任务方向偏移减小，均值 −0.050，最大 −0.126；
- **ΔD_⊥ > 0（46/46）**：正交扰动增大，均值 +0.070；
- **ΔD_total > 0（46/46）**：总白化修正增大，均值 +0.019。

即 CCA-ASF 以「更大的总修正」换取「更小的任务方向偏移」。局部机制**按设计生效**，
但印证了定理 4 的 trade-off：大 β 不创造可行方向，只把扰动从任务方向重分配到
正交方向，且总扰动略增。

## 2. 关键 trade-off（诚实）

CCA-ASF 减少任务方向偏移的代价是增大正交扰动，净总修正略增：

- 任务方向偏移：−0.050（改善）
- 正交扰动：+0.070（恶化）
- 总修正：+0.019（略恶化）

这**不是**「零成本的方向保护」，而是「方向重分配」。是否对真实任务有利，取决于
「任务方向代理 d」是否真的对应冻结 π0.5 的有效操作意图——这正是规格书 §11 强调的
科学门槛：**减少任务方向代理上的修正 ≠ 保留真实任务意图**。
