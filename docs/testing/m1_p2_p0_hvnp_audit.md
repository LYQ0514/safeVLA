## 0. 结论

> HVNP 在三个锁定状态（step54/57/59）上**正确区分**了「应当保留的安全名义动作」与
> 「必须替换的危险名义动作」：step57 名义安全 → 保留 N；step54/59 名义不安全 →
> 替换为干预最小的安全序列 L+A。AEGIS 候选在所有状态均 CAR 越界（1.149mm），
> 被安全契约正确排除。选择机制的两级语义（优先 N，否则最小干预）均得到验证。

## 1. 结果

| 状态 | N | A | Z+A | L+A | Hold+N | HVNP 选择 |
|---|---|---|---|---|---|---|
| step54 | ✗接触(63, 0.048mm) | ✗接触(59, **1.149mm**) | ✓ | ✓ | ✓ | **L+A** |
| step57 | ✓(0mm) | ✗接触(59, **1.149mm**) | ✓ | ✓ | ✓ | **N** |
| step59 | ✗接触(59, 0.207mm) | ✗接触(59, **1.149mm**) | ✓ | ✓ | ✗接触(61, 0.075mm) | **L+A** |

各候选 J_dev（干预幅度，越小越接近名义）：N=0 < A < L+A < Z+A < Hold+N。

## 2. 三项关键发现

### 发现 1：区分能力成立（核心验收）

HVNP 在三个状态做出**不同的正确选择**，覆盖完整谱系：

- **step57（名义安全）**：N 零接触、Dmax=0 → 保留 N，避免不必要干预；
- **step54（名义 grazing 接触）**：N 在 step63 有轻微接触（Dmax 0.048mm，CAR 合格
  但非零接触），A 在 step59 接触且 Dmax 1.149mm → 严格零接触契约下替换为 L+A；
- **step59（名义已进入接触）**：N 接触(0.207mm)，A 接触(1.149mm) → 替换为 L+A。

这正是「两类场景同时通过」的验证：名义安全时避免干预，名义危险时找安全替代。

### 发现 2：AEGIS 候选在三个状态全部 CAR 越界（1.149mm，可复现）

A 分支的 Dmax 恒为 **1.149mm**（> 1mm），接触 @ step59。这是继 G3 之后第二次、
且在三个不同分叉状态上一致的信号：**AEGIS 过滤的闭环行为比名义策略产生更严重的
物理扰动**。HVNP 将它作为候选放入安全契约验证，而不是默认 fallback，正确地将其
排除出安全集。

### 发现 3：step59 时 Hold+N 已太晚，但侧向避让仍有效

step59 的 Hold+N 仍接触（step61，Dmax 0.075mm）——hold 两步后名义接续无法避开
已形成的接近。但 L+A / Z+A（前两步侧向/抬升避让 + AEGIS 接续）仍安全。说明在
接触入口附近，**主动方向性避让优于单纯停止**。

## 3. 与用户预设的对照（诚实修正）

用户预设 step54 为「名义执行安全的正例」。数据显示：step54 的名义在严格 C_body=0
契约下**不安全**（step63 有 grazing 接触），但满足 CAR（0.048mm << 1mm）。这揭示
一个重要的门槛区分：**「零接触」（C_body）与「CAR 合格」（Dmax<1mm）是独立约束**。
step54 名义「CAR 合格但非零接触」，step57 才是真正的「名义完全安全」正例。

## 5. 尚未验证（不过度宣称）

1. 全时域自主决策（每个控制步判断保留/替换/避让）；
2. 完整 episode 的 CAR/TSR/SSR 改善；
3. 低开销「是否需要干预」的判断（当前每候选需一次完整 H=10 预演）；
4. 「几何替代动作选择能力」的独立证明——step57 说明避免不必要过滤成立，但 step54/59
   的 L+A 是从固定候选字典选的，尚非「从真实几何自动生成新方向」。
