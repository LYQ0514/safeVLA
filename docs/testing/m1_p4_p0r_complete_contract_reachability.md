## 0. 结论（回答决定性问题的答案）

> 在完整安全契约（含 mug 底座）下，对 S01/S04/S09 的 **10 个接近位置 × 60 个
> 多起点 IK**，均**未找到无碰撞的预抓取配置**。失败由两类原因构成：
> ① robot-底座接触（约 160/600 次）——底座确实阻挡抓取路径；② IK 未收敛
> （约 430/600 次）——固定朝下姿态下部分接近位置超出 Panda 可达空间。

**关键区分**：这不是「物理不可达」的证明。当前只测了**固定朝下抓取姿态**的
位置偏移，没有探索**抓取朝向变化**（斜抓、侧抓、俯仰抓）。IK 未收敛占主导，
说明「固定姿态 + 位置偏移」的搜索空间太窄，而非安全配置空间为空。

## 2. 失败类型的严格区分

### 类型 A：robot-底座接触（真实阻挡，约 27%）

`classify_ik_failure` 精确归因：当 IK 收敛到接近点后，机械臂（前臂 link5）与
`box_small_base_1_main` 的 box 几何（y 方向 size 0.0583）碰撞。底座确实占据
soup 附近空间——soup 在 base 上方 36mm，y 偏移仅 1-42mm（State04 仅 1mm）。

### 类型 B：IK 未收敛（搜索空间边界，约 71%）

**这是更重要的发现**：+X 侧向（soup 正 +x 方向，离底座最远）60/60 全部 IK
未收敛——说明该位置在**固定朝下姿态下超出 Panda 可达空间**（或 DLS IK 步数
不足），而非底座阻挡。

## 3. 空间关系澄清

- soup 的支撑是 `living_room_table_col`（桌面柱），**不是 mug 底座**；
- soup 与 mug 底座是两个独立 FREE 物体，空间相邻（soup-base dy 1-42mm，dz 36mm）；
- State02（P1b 成功）的 soup-base dy=42mm 最大，State04 仅 1mm——成功案例的
  soup 离底座更远。

## 4. 判决（严格按预设）

命中预设判决：

> **「全部预抓取 IK 均碰撞 → 记录搜索空间边界，研究抓取姿态或目标可达性」**

但需更精确：不是「全部碰撞」，而是「固定朝下姿态下，部分位置碰撞（底座）、
部分位置 IK 未收敛（可达空间边界）」。

## 5. 两种竞争假设的当前证据

| 假设 | 证据状态 |
|---|---|
| H-A：完整契约下仍有安全路径，但需更大搜索空间 | **未被排除**——只测了固定朝下姿态 |
| H-B：场景/预抓取约束使安全路径极难找 | 部分支持——底座确实阻挡（27% 底座接触）|

**关键**：71% 的「IK未收敛」说明当前搜索的**可达空间边界**才是主因，不是底座。
如果加入**抓取朝向变化**（斜抓/侧抓），IK 未收敛的比例可能大幅下降，进而可能
找到无碰撞解。

## 6. 下一步方向（待用户裁决，不自动推进）

## 7. 诚实边界

- 未证明「安全抓取路径不存在」，只证明「固定朝下姿态 + 位置偏移」的搜索空间无解；
- IK 未收敛 ≠ 不可达（可能是局部极小或迭代不足）；
- 未探索朝向自由度，这是后续必须补的。
