## 0. 结论

> step15 的三层分解显示：γ_QP == γ_cmd（M1 映射失配**排除**），
> 但 γ_real 与 γ_cmd 符号不同（G-S 从 +1.59mm 变为 −0.31mm）——
> **M2 控制执行失配成立**：OSC 阻抗控制单步跟踪能力不足，
> 目标「朝 soup 位移 1.59mm」在 25 substep（0.05s）内无法完成，
> 真实 EEF 位移被阻抗动态主导，甚至微远离。
> 横向位移 \|Δp_⊥\| 仅 0.4~1.4mm，M3 不是主因。

| 机制 | 判决 | 证据 |

## 3. 关键发现：代理用「运动学假设」，真实执行是「阻抗动力学」

AEGIS 的 QP 隐含假设：输出动作 → 末端移动「动作 × 0.05m」（运动学）；
但 OSC 阻抗控制（kp=150, kd 临界阻尼）在 25 substep（0.05s）内**追不上目标**，
真实位移远小于设定，且受重力/惯性影响，方向可能反转。

$$\text{代理假设: } \Delta p = \text{cmd} \times 0.05 \quad\not\approx\quad \text{真实: 阻抗动态主导}$$

## 4. d² 公式 ✗ 的含义

$d_{t+1}^2-d_t^2 = -2d_t\gamma_{real} + \|\Delta p_{real}\|^2$ 不成立 ⟹ **soup 本身在动**。
soup 不是静止的，单步内被扰动（微小），故「静止 soup 距离公式」不适用，
须用相对位移。

## 5. 边界

- 单步（step15）结果，不推广整条轨迹；
- 「OSC 跟踪不足」是所有动作共有的，不只 G-S，不否定几何方向；
- γ_real 微负（−0.31mm）量级很小，是否在更长时间步累积成远离需多步验证。

## 6. 对主线的意义

「几何-执行失配」精确定位为两层：
1. **代理几何保守**（R3-G2/G3：椭球过大排除安全动作）；
2. **代理执行模型失配**（G4-①：QP 用运动学假设，真实是阻抗动力学）。

两者都需解决，但**先解决「执行模型失配」更根本**——否则即使几何对了，
QP 以为「朝 soup 移 1.59mm」，真实只移 −0.31mm，任务方向约束仍无效。
