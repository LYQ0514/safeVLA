### 聚合修复

修复前，多个 MuJoCo contact points 被错误地当作独立连续事件。

修复后使用两级聚合：

```text
raw contact records
→ 同一 substep 内按 unordered geom pair 去重
→ 跨连续 substeps 合并 contiguous event
```

结果：

| 层级 | 数量 |
|---|---:|
| Raw native records | 116159 |
| Substep pair presences | 43720 |
| Contiguous events | 1756 |

满足：

```text
raw records >= substep pair presences >= contiguous events.
```

稳定支撑事件时长中位数为 25 physics substeps，即一个完整 control step，与物理语义一致。

## 8. task0 结果的证据边界

```text

```

```text

/ method_config / action_sequence_hash
```

```text

```

不得用新轨迹替历史 episode 重新贴标签。
