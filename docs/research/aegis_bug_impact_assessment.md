# AEGIS 复现 bug 修复对各研究线的影响面评估

> 日期：2026-11-04。回答「之前自己的方法哪些会受影响」。
> 背景：修复了 AEGIS 复现的两个根本 bug（①四元数约定 p1 偏移 16cm；②几何椭球未包围），
> 导致所有「依赖 AEGIS 末端椭球 CBF」的方法需要重验。

---

## 1. bug 影响的精确范围

两个 bug 都在 `src/safety/aegis_adapted.py`：

| bug | 影响 |
|---|---|
| 四元数约定（`_quat_wxyz_to_rot` 误当 wxyz） | 末端姿态 R1 的 y/z 轴符号翻转 → **末端椭球中心 p1 偏移 16cm**、`v_ref`/`a_v` 错误 |
| 几何椭球未包围（body 原点 + geom_size max） | 障碍物椭球中心错位 + **未包住碰撞几何**（68/88 顶点越界） |

**凡是用 `AegisSafetyLayer`（末端椭球 CBF-QP）的方法，其「安全过滤的定量行为」都受影响。**

## 2. 各研究线受影响情况（按依赖分层）

### 2.1 完全不受影响（✅ 无需重验）

| 线 | 原因 |
|---|---|
| M3-P0（2D 单积分器排序反转） | `experiments/m3_p0_future_burden_test.py` **零依赖 AEGIS/SafeLIBERO**，纯 2D 机制实验 |
| 支撑检测模块（`detect_supports`） | 纯 MuJoCo 真值（`d.xpos` + 接触），不依赖 p1/椭球 |
| 支撑感知理论（`support_aware_theory.md`） | 纯数学（支撑传递引理、盲区命题、不变性定理） |
| 传递链物理事实（碰底座→带 mug） | MuJoCo 物理规律，不依赖 AEGIS |

### 2.2 受影响（⚠️ 需重验「AEGIS 相关的定量」）

| 线 | 受影响部分 | 不受影响部分 |
|---|---|---|
| **支撑感知** | 「AEGIS 漏保护底座」定量（S05/S06 残留位移）、「支撑感知 CBF 保护底座」的干预效果（344→6mm 等离线 replay） | 支撑检测、理论、传递链物理事实 |
| **CCA-ASF** | 全部（基于 AEGIS CBF-QP 改目标函数，p1 错误导致方向重分配的定量全错） | 白化度量数学（metric.py 的数学定义） |
| **M3-P1a**（真实 π0.5 迁移） | 全部（用 AegisSafetyLayer 的干预负担定量） | M3-P0 的 2D 机制 |
| **circulation / grasp-aware / 分离约束** | 全部（基于 AEGIS 的扩展，本轮已标记作废） | — |
| **M0/M1 各阶段**（design gate、HVNP、reachability 等） | 所有用 AegisSafetyLayer 的定量 | 纯接触检测、几何分析 |

### 2.3 关键判断：受影响的本质

**受影响的不是「方法思路」，而是「基于 AEGIS 的实证定量」**。具体：

1. **支撑感知**：它的**核心洞察**（「hazard 的安全 = 不碰 hazard + 不碰支撑物」）和
   **检测模块**（detect_supports）完全不受影响；受影响的只是「在 bug 时代的 AEGIS 上
   测出的干预效果数字」（S05 344→6mm 等）——这些数字的 p1 是错的，需要修复后重测。

2. **CCA-ASF**：它的「方向重分配」思路不受影响，但「闭环安全恶化（mug 撞飞 27mm）」
   这个**归档判决**基于 bug 时代的 AEGIS，需要重验——修复后 p1 正确，方向重分配是否
   还会引入副作用，未知。

3. **M3-P1a**：它的「排序反转」机制结论（Entry vs Persistent、幅度 vs 次数）基于
   AEGIS 的干预负担，定量需重验。但 M3-P0 的 2D 机制（排序反转存在）不受影响。

## 3. 影响面总结表

| 研究线 | 核心结论 | 受 bug 影响程度 |
|---|---|---|
| CCA-ASF | 方向重分配闭环安全恶化（归档否决） | 🔴 **重度**：全部定量需重验，判决可能反转 |
| M3-P0 | 排序反转在 2D 存在 | 🟢 无影响 |
| M3-P1a | 真实迁移：Entry 4/4、Persistent 0/4 | 🔴 **重度**：AEGIS 干预负担定量需重验 |
| 支撑感知-检测 | detect_supports 6/6 正确 | 🟢 无影响 |
| 支撑感知-理论 | 传递引理/盲区/不变性 | 🟢 无影响 |
| 支撑感知-干预 | 保护底座切断传递（344→6mm） | 🟡 **中度**：机制对，定量需重测 |
| circulation | 打破平衡点（21→7.4cm） | 🔴 重度（本轮已作废） |
| grasp-aware | 接近小椭球有效 | 🔴 重度（本轮已作废） |
| 分离约束 | soup-mug 分离降碰撞 | 🔴 重度（本轮已作废） |

## 4. 诚实结论

1. **受影响面很广**：几乎所有「基于 AEGIS 安全过滤」的实证定量都需要重验——这是
   四元数 bug 从最早提交就存在、污染所有 AEGIS 复现的必然结果；

2. **但「方法思路」和「不依赖 AEGIS 的结论」仍然有效**：支撑感知的核心洞察 + 检测
   模块、M3 的 2D 机制、所有纯数学理论，都不受影响；

3. **最需要警惕的是 CCA-ASF 的归档判决**：它「闭环安全恶化 → 否决」的结论完全基于
   bug 时代的 AEGIS（p1 偏移 16cm），修复后这个「恶化」是否还成立**未知**——可能
   方向重分配在正确的 p1 下并不恶化，甚至改善。这是「作废重验」的最高优先级。

4. **circulation / grasp-aware / 分离约束**：这三个是「本轮 AEGIS 归因」的产物，
   已经在本轮明确标记作废（见 `aegis_metric_attribution.md` 的作废标记），它们的
   「问题」（末端无法接近 soup、禁区 19.3cm）本身可能就是 bug 假象，修复后已不成立。

## 5. 建议的优先级

若要继续之前的线，重验优先级：

1. **支撑感知**（最优先）：核心洞察 + 检测 + 理论都有效，只需重测「干预效果的定量」
   ——这是最接近「可发表」的线；
2. **CCA-ASF 重验**：确认「方向重分配是否真的闭环恶化」——若修复后不恶化，则归档
   判决需要改写；
3. **M3-P1a 重验**：确认 Entry/Persistent 的排序反转在正确 AEGIS 下是否仍成立。

> 注意：所有这些重验，都应基于**本次已修复的代码**（SHA `b2226d9`）或后续修复，
> 且用确定性 PnsgPolicy（CRN seed）避免 π0.5 跨 run 非确定性的干扰。
